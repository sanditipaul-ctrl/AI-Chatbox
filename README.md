# Chatbox 💬

A simple chatbox made using HTML, CSS, and JavaScript. Users can type messages and get replies from the bot.

## Features

* Send messages by clicking the Send button.
* Press Enter to send messages.
* Bot replies to different messages.
* Chat automatically scrolls to the latest message.
* Simple design with a gradient background.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Type a message and click Send.

## Note

This is a basic chatbot project. It uses predefined replies and does not use AI.
